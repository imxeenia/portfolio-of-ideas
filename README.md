# Made of Moments ✳

Авторское портфолио идей, мероприятий и путешествий в эстетике **Creative Studio**.

## Зачем этот проект
Личный архив идей и воспоминаний, а также профессиональная демонстрация организации, планирования, дизайна и креативного мышления.

## Как открыть сайт
Откройте `index.html` в браузере. Никакая установка не нужна. Для Google Fonts потребуется интернет, предусмотрены резервные системные шрифты.

## Структура
- `index.html` — главная страница, стили и шаблон страницы кейса.
- `src/app.js` — данные проектов и навигация.
- `docs/DESIGN_SYSTEM.md` — **главный стандарт фирменного стиля, цветов, компонентов и правил развития**.
- `docs/TYPOGRAPHY_SPACING.md` — **эталон размеров шрифтов и единых отступов для mobile/tablet/desktop**.
- `src/design-tokens.css` — токены шрифтов/интервалов и их применение в сайте.
- `docs/CONCEPT.md` — дизайн-концепция и архитектура.
- `docs/CASE_TEMPLATE.md` — правила подготовки кейса.
- `docs/ROADMAP.md` — дорожная карта и этапы.

## Проекты
1. Halloween Birthday — день рождения Насти.
2. Baltic Escape — путешествие в Калининград, ноябрь 2026.
3. Girls Night — девичник.
4. My Birthday — личный праздник.

## Текущий статус
Первая версия интерактивного прототипа. У всех четырёх проектов есть страницы, но контент во многом демонстрационный. Фотографии пока заменены графикой и заглушками. Планирование не выдаётся за реализованные результаты.

**Приватный GitHub-репозиторий не равен опубликованному сайту.** Публичный релиз согласовывается отдельно.

## Правила развития
Сохранять утверждённый Creative Studio стиль, адаптивность и навигацию. Не менять факты без подтверждения. Фотографии гостей и персональные документы добавлять только с разрешения и после проверки приватности.

# Аудит отступов Made of Moments — 20.11.2026

**Статус:** аудит исходников, не визуальная приёмка. **Изменения дизайна:** не вносились.  
**Проверенные файлы:** `index.html` (встроенный legacy CSS, разметка главной/обо мне/универсального кейса), `src/design-tokens.css`, `src/app.js`, `docs/TYPOGRAPHY_SPACING.md`, `docs/DESIGN_SYSTEM.md`, `docs/CONCEPT.md`, `docs/CASE_TEMPLATE.md`, `docs/ROADMAP.md`.

## Норматив
`docs/TYPOGRAPHY_SPACING.md` — основной источник истины. Шкала: **4, 8, 12, 16, 24, 32, 48, 64, 96px**.
Контейнер: **16 / 24 / 48px** (телефон/планшет/ПК). Крупные секции **64 / 80 / 96px**. Заголовок секции → содержимое **24 / 32 / 32px**. Сетка карточек **16 / 24 / 24px**. Подразделы кейса **48 / 64 / 64px**. Абзацы **16px**. Лейбл → заголовок **8 / 8 / 12px**. Примечание: исключения у художественных коллажей допустимы с комментариями; это не разрешение на случайные смысловые интервалы.

## Покрытие
Текущий сайт — три HTML-экрана (`home`, `aboutPage`, `detail`). `home` включает Hero, My ideas, Little Stories, тизер About Me, общий footer и мобильную панель. `detail` — один универсальный шаблон, используемый для шести проектов: Halloween, Girls Night, My Birthday, Kaliningrad, Housewarming, March 8. Правки в шаблоне затрагивают все шесть.

## Итоги по областям

## Приоритет исправления
**P1:** универсальный кейс: убрать нерегламентированные 50/90/55px вокруг баннера; 15px в строках метаданных; 30/14px в moodboard и facts; 42px под служебными номерами; три inline-styles. Сохранить недавнее решение об отсутствии линии над «Формат».

**P2:** About Me: удалить устаревшие дублирующие переопределения; согласовать компактные пользовательские исключения с нормативным файлом без возврата больших пустот; единообразно применять токены для текстовых промежутков, не трогать полароидные координаты.

**P3:** mini-cards, footer, drawer: стабилизировать ритм по токенам; компактные художественные исключения задокументировать.

**P4:** проверить переполнения и реальное расстояние на ширинах **320, 375, 390, 430, 620, 768, 1024, 1280, 1440px**, при zoom 200%, на iOS Safari и desktop. Кодовый аудит не доказывает отсутствие визуальных конфликтов и горизонтального скролла.

## Принципы внедрения
- Точечные CSS-правки после legacy слоя, без произвольного изменения палитры, типографики, маршрутов и фотографий.
- Не применять значения «по норме» поверх согласованного пользователем компактного About Me, пока не сверены визуальный результат и исключение.
- Перед каждой правкой — отдельный коммит. Обновлять `docs/DESIGN_SYSTEM.md` при изменении правил и `docs/TYPOGRAPHY_SPACING.md` только после утверждения исключений.
- После изменений проверять опубликованный GitHub Pages, не считать `git commit` доказательством успешной публикации.

**Вывод:** общее токенизированное ядро действует, но сайт пока не полностью соответствует нормативу. Наиболее существенные отклонения в общем шаблоне кейсов и накопленных переопределениях About Me. До исправлений и визуального тестирования заявлять полное соответствие нельзя.

# Универсальный шаблон кейса

1. **Обложка** — название, визуальная концепция, дата и категория.
2. **Контекст** — для кого, зачем, исходные пожелания и ограничения.
3. **Моя роль** — конкретные личные задачи и зона ответственности.
4. **Концепция** — настроение, референсы, цвета, мудборд.
5. **Организация** — исследования, альтернативы, бюджет, сценарий, тайминг, логистика и документы.
6. **Реализация** — настоящие фотографии и авторские материалы.
7. **Итог** — подтверждённые результаты, полезные выводы, профессиональные навыки.

## Обозначения статуса
- Concept — только идея.
- In progress — в работе.
- Completed — реализовано.

## Редакционные правила
Не выдумывать достижения и цифры. Не выдавать концепцию за реализованное мероприятие. Указывать совместную работу, когда она была. Не публиковать лица других людей и личные сведения без согласия.

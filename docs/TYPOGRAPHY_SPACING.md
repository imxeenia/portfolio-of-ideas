# Typography & Spacing — Made of Moments
**Версия:** 1.0 · **Дата:** 19.11.2026 · **Статус:** фирменный стандарт для следующих изменений сайта.

> Принято для проекта: две семьи шрифтов, одна семантическая шкала заголовков и текста, токенизированные отступы, плавная адаптация и проверка увеличения текста. Конкретные числа ниже — **наше дизайнерское решение на основе исследований**, а не прямые юридические требования WCAG. Дизайн должен оставаться Creative Studio.

## 1. Основания и ссылки
1. [USWDS Typography](https://designsystem.digital.gov/components/typography/) — рекомендует эффективный размер большинства текстов не менее 16px, баланс длины строк, межстрочный интервал и иерархию.
2. [USWDS Spacing Units](https://designsystem.digital.gov/design-tokens/spacing-units/) — масштаб интервалов на основе 8px с малыми половинными шагами.
3. [USWDS Design Tokens](https://designsystem.digital.gov/design-tokens/) — повторно используемые имена значений для цвета/шрифтов/интервалов.
4. [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/) — критерии 1.4.4 (увеличение текста до 200%), 1.4.10 (перекомпоновка на 320 CSS px), 1.4.12 (не терять функциональность при пользовательской настройке расстояний).
5. [Web.dev: Responsive Typography](https://web.dev/learn/design/typography) и [Chrome: Responsive Design](https://developer.chrome.com/docs/modern-web-guidance/guides/css/responsive-design) — адаптивная типографика, ограниченный `clamp()` вместо неограниченного `vw`.
6. [Material Design 3 Typography](https://developer.android.com/develop/ui/compose/designsystems/material3) — семантические роли display/headline/title/body/label, использованы как принцип, **не как набор чисел для нашего сайта**.

**Важно:** WCAG не устанавливает общую обязательную нижнюю границу 16px для всех текстов, это рекомендация USWDS. WCAG 1.4.12 проверяет возможность пользовательской настройки (минимум line-height 1.5, paragraph spacing 2em, letter spacing .12em, word spacing .16em) без потери информации; это не значит, что обычный дизайн обязан всегда иметь paragraph margin 2em.

## 2. Шрифты и роли
- **DM Sans:** обычный текст (400), вводные абзацы (400–500), самые крупные плакатные заголовки (800), заголовки разделов (700–800). Семейство `'DM Sans', Arial, sans-serif`.
- **Manrope:** названия карточек (700), компактные интерфейсные заголовки (700), навигация (700), кнопки (700), служебные лейблы и категории (700–800). Семейство `'Manrope', Arial, sans-serif`.
- Не загружать произвольные веса и семейства. Сохранять кириллицу; протестировать начертания и переносы.
- **Плакатные заголовки:** уменьшенный letter-spacing возможен только у крупных заголовков; для длинного текста и мелких надписей — не уплотнять.

## 3. Размеры и межстрочный интервал
Размеры — CSS px при корневом 16px. В реализации использовать rem для основных размеров и rem+vw в clamp для заголовков, с zoom-проверкой.

| Токен / роль | Телефон 320–619px | Планшет 620–1023px | Desktop >=1024px | Line-height | Вес |
|---|---:|---:|---:|---:|---|
| `--type-display` Hero | 40–52px | 52–76px | 76–112px | 0.98–1.03 | DM Sans 800 |
| `--type-page` H1 страницы | 36–44px | 44–60px | 60–88px | 1.00–1.08 | DM Sans 800 |
| `--type-section` H2 | 30–36px | 36–44px | 44–60px | 1.08–1.15 | DM Sans 800 |
| `--type-subheading` H3 | 22–26px | 26–28px | 28–36px | 1.16–1.24 | DM Sans 700 |
| `--type-card-title` | 19–22px | 21–24px | 22–26px | 1.18–1.28 | Manrope 700 |
| `--type-lead` | 17–18px | 18–19px | 19–20px | 1.45–1.60 | DM Sans 400–500 |
| `--type-body` | 16px | 16–17px | 17–18px | 1.55–1.70 | DM Sans 400 |
| `--type-nav` | 14–15px | 14px | 14px | 1.35–1.5 | Manrope 700 |
| `--type-button` | 14px | 14px | 14px | 1.4–1.5 | Manrope 700 |
| `--type-caption` | 12–13px | 12–13px | 12–13px | 1.4–1.55 | Manrope 500–700 |

Примечание: подписи размером 12–13px — **только необязательные короткие метаданные**, не содержательный текст, не инструкции и не единственный способ понять действие. Если подпись важна, минимум 14–16px.

### Привязка к элементам
- Hero `Ideas. Plans. Magic.`: `--type-display` с отдельной проверкой переноса каждой строки.
- H1 кейса: `--type-page`.
- `Projects`, `Little Stories`, `About Me` — `--type-section`.
- Внутренние смысловые подзаголовки — `--type-subheading`.
- Названия крупных и мини-карточек — `--type-card-title`, у мини-карточки допускается нижняя граница.
- Повествовательные абзацы, опыт работы, описание обучения — `--type-body`.
- Вводный текст/интро — `--type-lead`.
- Даты/категории — `--type-caption`; навигация/кнопки по собственным токенам.

### Ограничения композиции
- Длинный текст: целевая длина строк 55–75 символов, максимум около 75ch, для короткого вводного текста — 48–60ch.
- Не задавать фиксированную высоту содержательным текстовым карточкам; `min-height` только при необходимости.
- Не использовать `vw` отдельно для шрифтов. Использовать `clamp()` с `rem`-ограничениями или breakpoint-переопределения.
- Проверять 200% zoom и настройки увеличения текста в браузере; не отключать масштабирование.

## 4. Пространственная система (spacing)
**Единая шкала:** `4, 8, 12, 16, 24, 32, 48, 64, 96px`.
Никаких произвольных значений для обычных смысловых отступов. Дополнительные величины допустимы для художественного коллажа и точных оптических компенсаций с комментарием в коде.

| Токен | Размер | Назначение |
|---|---:|---|
| `--space-1` | 4px | иконка + текст, микроинтервал |
| `--space-2` | 8px | тесно связанные строки |
| `--space-3` | 12px | категория + название, малые группы |
| `--space-4` | 16px | абзацы/интервалы обычных элементов |
| `--space-6` | 24px | внутренние поля карточек |
| `--space-8` | 32px | между группами контента |
| `--space-12` | 48px | крупные подсекции |
| `--space-16` | 64px | смысловые подразделы |
| `--space-24` | 96px | большие секции desktop |

### Семантические интервалы
| Отношение | Телефон | Планшет | Desktop |
|---|---:|---:|---:|
| Поля контейнера слева/справа | 16px | 24px | 48px |
| Между крупными секциями | 64px | 80px | 96px |
| Заголовок секции → сетка/контент | 24px | 32px | 32px |
| Между карточками сетки | 16px | 24px | 24px |
| Внутри крупной карточки | 16px | 24px | 24px |
| Между смысловыми подразделами кейса | 48px | 64px | 64px |
| Между абзацами | 16px | 16px | 16px |
| Лейбл → заголовок | 8px | 8px | 12px |
| Заголовок → пояснение | 12px | 16px | 16px |
| Высота CTA (ориентир) | >=44px | >=44px | >=44px |

На планшете `80px` — семантический адаптивный токен `--space-section-tablet`, не случайное исключение.

### Правила композиции
- Секция всегда использует общий `--section-pad-block`, а не отдельное произвольное `padding-top/bottom`.
- Расстояния между карточками задаёт один `--card-gap` на данной ширине экрана; избегать отдельных margin у каждой карточки.
- Внутренние элементы карточки используют `--card-padding`; не растягивать все тексты по высоте для искусственной симметрии.
- Заголовок/описание/метки группируются визуально и повторяются одинаково между секциями.
- Декоративный Hero допускает исключения из шкалы **только для позиционирования графики**, но не для основных отступов контента.
- Соблюдать вертикальный ритм относительно базового интервала 8px; исключения 4px для микроэлементов.

## 5. Breakpoints и адаптив
- Mobile: до `619px`, desktop layout должен быть одноколоночным.
- Tablet: `620–1023px`, возможны 2 колонки, если карточки читаемы.
- Desktop: `>=1024px`, основная сетка 2 колонки; максимальная ширина контейнера `1400px`.
- Проверки обязательны на `320, 375, 390, 430, 620, 768, 1024, 1280, 1440px`.
- Не обрезать текст и изображения, не скрывать важные элементы, не допускать горизонтальную прокрутку.
- Длинные заголовки переносить предсказуемо, без `nowrap` у содержательных текстов.
- Графические плакатные элементы внутри тематических обложек масштабируются отдельно от текстовой иерархии интерфейса.

## 6. Доступность и тесты приемки
- Zoom 200%: текст не исчезает, управление работает.
- Reflow при ширине 320 CSS px: нет горизонтальной прокрутки смыслового контента.
- При пользовательских текстовых интервалах WCAG 1.4.12 содержимое не перекрывается и не пропадает.
- Любая кликабельная карточка — с клавиатурным фокусом и tap на iPhone.
- Проверять контраст (WCAG AA ориентир: 4.5:1 обычный текст и 3:1 крупный текст), в частности тексты поверх тематических цветов.
- Проверить `prefers-reduced-motion`, не строить навигацию на hover.
- Перед релизом визуально сравнить desktop/mobile по контрольному листу.

## 7. Источник истины и изменения
- Этот документ определяет **нормативные размеры и интервалы**.
- `src/design-tokens.css` содержит машиночитаемые CSS-переменные этого стандарта.
- `docs/DESIGN_SYSTEM.md` содержит визуальную идентичность/цвета/компоненты.
- При изменениях шрифтов/отступов **обновлять и документацию, и CSS одновременно**.
- Для существующего HTML проверить, что новые токены действительно подключены и используются. Нельзя считать документацию уже применённой в интерфейсе без проверки.

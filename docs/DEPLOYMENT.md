# Публикация сайта Made of Moments

## Цель
Развивать сайт из приватного репозитория `imxeenia/portfolio-of-ideas`, открывать рабочий предпросмотр с iPhone и ПК по обычному HTTPS-адресу. Существующий сайт `imxeenia.github.io` не изменять.

## Важно о GitHub Pages
GitHub Pages в бесплатном тарифе GitHub доступен для **публичных** репозиториев; для публикации из **приватного** репозитория требуется подходящий платный тариф (GitHub Pro/Team/Enterprise). Открытая страница GitHub Pages доступна посторонним даже если репозиторий приватный (за исключением специальных корпоративных настроек приватной публикации).

## Рекомендуемая стратегия
1. Оставить `portfolio-of-ideas` приватным источником.
2. Для бесплатного размещения выбрать хостинг, поддерживающий деплой из приватного GitHub-репозитория (например Cloudflare Pages), либо после отдельного согласования использовать отдельный публичный репозиторий только для сборки/публикуемых файлов.
3. Настроить автоматическую сборку и публикацию при изменениях `main`.
4. Проверить ссылку с iPhone: главная, четыре карточки, возврат назад, прямое открытие страниц, мобильная верстка.
5. Никогда не размещать в публичном сайте частные данные, личные адреса, контакты гостей, бронирования или фотографии без согласия.

## Ограничения
- Приватность GitHub-репозитория **не делает опубликованный сайт приватным**.
- Для прямой публикации через GitHub Pages из приватного репозитория сначала проверить тариф и доступность Pages в `Settings → Pages`.
- Никакую уже существующую публикацию `imxeenia.github.io` не менять.
- Не сообщать пользователю публичный URL до подтвержденного успешного деплоя.

## Перед приемкой
- Сравнить визуал главной со **согласованным исходным HTML-прототипом** (обложка «Ideas. Plans. Magic.» с крупной типографикой; не заменять на иной дизайн).
- Проверить кликабельность всех проектов в реальном мобильном Safari, а не в предпросмотре вложения.
- Оформить карту проекта с различением Concept / In Progress / Completed.
